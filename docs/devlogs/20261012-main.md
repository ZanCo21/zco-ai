# Development Log — 2026-10-12 Docker Native Dependency Build

## Summary
Fixed Docker dependency installation failing while `better-sqlite3` compiled its native addon.

## Changes
- Added Python, make, and g++ to the Docker build stage so node-gyp can compile `better-sqlite3`.
- Configured node-gyp to use the Node headers already included in the official Node image, avoiding an additional header download during install.
- Added the C++ runtime library to the final image for the compiled addon.
- Updated the application image to Node 22, which satisfies `better-sqlite3@13`'s Node `>=22` engine requirement.
- Removed the build-time Google Fonts fetch and set a local system font stack so builds work without access to `fonts.googleapis.com`.
- Documented the Node version requirement and native dependency troubleshooting in `DOCKER.md`.

## Validation
- A native SQLite smoke test exposed a segmentation fault when loading `better-sqlite3@13` on Node 20, below its declared Node `>=22` engine requirement.
- `pnpm build` passed locally.
- `docker compose --progress plain build` passed for the app and AI worker images.
- The app image's runtime `better-sqlite3` smoke test passed against an in-memory database.
