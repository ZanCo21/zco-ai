## Architecture

```
Network: zco-network (bridge)
├── ollama:11434
│   └── health: /api/tags
├── ai-worker:8001
│   ├── health: /health
│   └── depends_on: ollama (healthy)
└── app:3000
    ├── health: /
    └── depends_on: ai-worker, ollama (healthy)

Volumes:
├── ./data → /app/data (SQLite + uploads)
└── ollama-models → /root/.ollama (persistent model cache)
```

## Docker Service Communication
- Next.js → Python worker: `http://ai-worker:8001`
- Next.js → Ollama: `http://ollama:11434`
- Python worker → Ollama: `http://ollama:11434`

Container networking via Docker DNS resolves service names automatically.

## Healthchecks
All services implement healthchecks:
- Ollama: `curl http://localhost:11434/api/tags`
- AI Worker: `curl http://localhost:8001/health`
- Next.js: `curl http://localhost:3000`

Startup order enforced: ollama → ai-worker → app

## Usage
```bash
docker compose up --build
# Access: http://localhost:3000
```
