# Devlog 2026-09-29 — main

## Bug Fix: Retrieval chunk index mapping

### Problem
- `maxSimilarity` = 0.2479, `threshold` = 0.2, should be `relevant = true`
- `/api/chat` returned "tidak ditemukan" or wrong sources
- Top-K returned duplicate `chunkId` values

### Root Cause
- `retrieval.ts` sent DB `chunkIndex` (resets to 0 per knowledge) as `chunk_index` to Python
- `retrieval.py` echoed back `chunk.get("chunk_index")` instead of array position `chunk_idx`
- When mapping results back, `chunks[r.chunk_index]` hit wrong array elements → duplicate/wrong chunkIds

### Fix
1. **`src/lib/retrieval.ts`** — use array `index` (global position) instead of `c.chunkIndex` when formatting chunks for Python
2. **`ai-worker/retrieval.py`** — always return `chunk_idx` (enumerate position) instead of `chunk.get("chunk_index", chunk_idx)`

### Files Changed
- `src/lib/retrieval.ts`
- `ai-worker/retrieval.py`
